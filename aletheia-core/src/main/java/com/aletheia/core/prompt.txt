double a = 1.0825;
double b = 0.0001;
System.out.println(a + b);

You will see: 1.0826000000000002

Not 1.0826. The extra 0000000002 is floating-point rounding error. In a trading system this causes:





Wrong position sizes (you risk $101.23 instead of $100.00)



Wrong stop loss placement (SL is 1 pip off)



Wrong P&L calculation (your trade journal is inaccurate)
